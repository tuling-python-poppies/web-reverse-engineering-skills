# Doctrine Index

Use this file only for family-level invariants when the target is still broad. It contains no execution recipes; after an invariant identifies the problem class, route through `reference-router.md` to one focused owner.

## Evidence

1. **Wire outranks presentation.** Final network route, headers, cookies, bytes, and response semantics outrank page names, visible helpers, rendered shells, and archived notes.
2. **Names do not prove algorithms or issuers.** A field named sign, session, nonce, MD5, or verification token still requires fixed-input proof and writer attribution.
3. **Environment mismatch is evidence.** Differences across live/local output, property reads, reflection, identity, enumeration, timing, or load order identify the missing surface; they do not prove browser-only delivery.
4. **Observer effect is part of the experiment.** Preserve an untouched baseline before broad hooks, breakpoints, or monkey patches and treat hook-only failures as instrumentation evidence.
5. **Semantic acceptance outranks shape.** Status, token length, fewer exceptions, and browser-looking output are health signals, not proof of the business contract.

## State And Transport

6. **Dynamic state is broader than signatures.** Cookies, wrappers, challenge output, verifier rounds, side assets, response decoders, and account context may be the actual moving part.
7. **Provenance outranks superstition.** Attribute each cookie/token to HTTP, page code, bootstrap execution, redirect/frame/worker side effects, or local minting before designing refresh.
8. **One coherent chain is the unit of proof.** Do not mix entry responses, cookies, assets, verifier rounds, storage, counters, or tokens across neighboring sessions unless reuse is separately demonstrated.
9. **Admission is separate from application logic.** TLS/ALPN/HTTP version/UA/route policy, authentication, business authorization, and active tenant/shop/org context are distinct gates.
10. **Packet framing is separate from inner crypto.** Serialization, field slot, canonical URL, prefix/version, checksum, alphabet, lengths, state slices, key normalization, cipher, and payload anchor each require proof.
11. **Public is not unsigned.** Anonymous visibility does not remove entry cookies, bootstrap envelopes, route-specific permissions, or list-versus-detail boundaries.
12. **Server-issued state should not be reinvented.** First inventory issued ids, work factors, asset URLs, answer schemas, wrappers, and lifetimes; rebuild only what the server does not provide or cannot refresh.

## Scope And Escalation

13. **Narrow exceptions remain narrow.** A page-specific header, transport profile, cookie rotation, route pivot, or parser exception must not contaminate the whole collector.
14. **Escalate one rung at a time.** Name the surviving proof, exact blind spot, and why the next layer is the smallest layer that answers it.
15. **Embedded runtimes are scalpels.** They may return one cookie, URL, header set, body, proof, or decoded payload; Python keeps live-egress ownership and the runtime must not become a second browser.
16. **Harvest beats over-solving.** When a reviewed local runtime already exposes the authoritative artifact at a getter, serializer, packer, or egress boundary, full VM/DOM parity is not the goal.
17. **Weak enforcement remains conditional evidence.** One route accepting an empty or simplified field does not remove that field from stricter route families.

## Data And Delivery

18. **Pagination and raw source are protocol surfaces.** Route cutoffs, next-page metadata, inline handlers, entity decoding, coordinate spaces, counters, and frame tags can be replay-critical.
19. **Enumeration and hydration are separate contracts.** Preserve stable identifiers and normalized/raw decoded outputs so expensive details can be fetched or backfilled independently.
20. **Stateful streams require transcripts.** Pairing/login, key schedules, acks, heartbeats, counters, reconnects, receipts, and media derivation belong to the protocol model.
21. **Verifier failures must be split by surface.** Protocol, compute, perception, and behavior each need independent evidence; one failure must not masquerade as another.
22. **Clean positive samples outrank contaminated failures.** A failed hooked/automation/browser-debug round is environment evidence first; do not tune tracks or answers until a clean success or clean failure bounds the verifier surface.
23. **Delivery must be local, explicit, and testable.** A browser profile, hidden refresh click, unexplained decoder, or pasted rotating state is not a browser-free collector.

## Maintenance

24. **Small facts age better than narrative.** Preserve routes, slots, shapes, decode order, state-chain rules, and acceptance checkpoints rather than copied credentials or long site stories.
25. **Counterexamples constrain better than slogans.** Repeated tempting shortcuts belong in `anti-patterns-playbook.md` with one smallest honest move and one direct self-check.
