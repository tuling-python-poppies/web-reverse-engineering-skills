# Multi-Writer Field Playbook

Use this playbook when one query, header, cookie, or body field has disjoint value shapes or can be written by more than one client path.

## Core Rule

A field name does not identify one algorithm. Prove the writer present on semantically accepted wire traffic before packaging any generator.

## Workflow

1. Freeze at least two accepted wire values for the same field. Record length band, prefix, separators, alphabet, request attempt, URL/body binding, session binding, and companion state.
2. Classify writer paths, for example compact signer, environment payload, challenge rewrite, retry mutation, cookie projection, wrapper injection, or cached bootstrap value.
3. Map every class to a runtime call stack, state writer, or transport mutation boundary. Initiator and egress evidence outrank a source-only candidate.
4. Mark which class appears on accepted business responses. A fixed-vector match for another class remains local proof for that class only.
5. Prove refresh and binding independently: URL, body, page, timestamp, session, cookie, route, or response echo.
6. Test one-variable negative controls. Do not construct an unobserved hybrid by concatenating segments from different writer classes.

## High-Value Signals

- two non-overlapping length bands for one field
- a compact value on the first attempt and a larger value after challenge execution
- a source function that never appears in accepted egress
- a session-stable prefix joined to a request-bound body
- a wrapper that overwrites a value after the application signer returns
- exact captured URL replay succeeds while fresh values from the recovered candidate fail

## Handoff

Report:

```text
field:
writerClasses:
acceptedWriter:
nonAcceptedWriters:
acceptedShape:
binding:
refreshBoundary:
decisiveEgressEvidence:
negativeControl:
residualUncertainty:
```

If the accepted class is a challenge rewrite, return the final URL/cookie/body artifact to Python. If it is a local algorithm, require fixed-input parity and repeated semantic acceptance. If more than one accepted class remains possible, do not choose by convenience.
